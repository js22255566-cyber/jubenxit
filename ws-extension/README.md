# 对白工坊 WhatsApp 网页联动验证版

1. 下载并解压网站“设置 → WhatsApp 联动”提供的扩展 ZIP。
2. Chrome 打开 chrome://extensions（Edge 使用 edge://extensions），开启开发者模式，选择“加载已解压的扩展程序”，选择包含 manifest.json 的目录。
3. 打开 https://web.whatsapp.com/ 并扫码登录，打开要绑定的群。群里需已有可见消息；扩展只从当前页面确认群，不读取其他群、联系人或登录凭据。
4. 点击浏览器工具栏本扩展的图标，选择“绑定当前打开的群”。回到网站，打开“设置 → WhatsApp 联动”，检测连接后启动联动。
5. 先在自己控制的测试群发送一条无敏感内容的文字，核对发送者、群和正文。此版本只支持文字；图片会明确标记未发送，不会只发送文字而漏掉附件。

网站只会转发启用后由你新发、且已保存成功的消息；不会自动补发历史、编辑、恢复或复制的消息。请保持网站与绑定的 WhatsApp 标签页打开，并停留在绑定群。

状态“已提交 WS”只表示找到 WhatsApp 网页上的新发送气泡，不等于已送达或已读。“结果未知”不自动重发；请到群中核对。只有确认未点击发送的失败可手动重试。扩展和网站均留有消息 ID 防止重复，但这不是 WhatsApp 服务端的幂等事务。

关闭标签页、扫码过期、网页 DOM 更新均会影响联动。它不是 WhatsApp 官方 API，可能受平台条款和账号限制影响。登录凭据留在 WhatsApp 网页中；扩展不导出凭据。发送者始终是当前登录账号，不是系统里的虚构角色。

本版本未在用户真实账号完成联通测试，需安装后验证。只在 Chrome/Edge 桌面版使用。

0.1.1 更新：兼容不带 title 的群名称和其他可见消息标识属性。不能确认群时点击“检查当前页面 → 复制诊断信息”，诊断仅含节点数量与匹配状态，不含聊天正文、成员、群编号或登录信息。更新时替换原扩展目录文件，在扩展管理页点击重新加载，再刷新 WhatsApp 和网站。

0.1.2 更新：绑定/检测时若 WhatsApp 接收脚本未加载，自动对明确的 WhatsApp 标签页补载。绑定后尝试修复已打开的对白工坊工作台连接。修复仅重试读取，不重试实际发送。更新需要替换原目录并在扩展管理页重新加载；如浏览器询问权限，所需网站仅 WhatsApp 和对白工坊。
